## 3. Emptiness supplies a finite inverse in the original ideal

Suppose `Z_t` were empty. Its actual affine chart has ring

```
R_i / ((s_i)_0, (s_i)_1, (s_i)_2).
```

A nonzero commutative ring has a prime ideal. Therefore that quotient is
the zero ring, and there are coefficients `c_(i,a) in R_i` such that

```
sum_a c_(i,a)*(s_i)_a = 1.
```

Define the concrete ideal element

```
a_i = sum_a c_(i,a)*l_(i,a) in I_i.
```

It satisfies `phi_i(a_i) = 1`. This is a finite construction from a
unit-ideal identity, not a hypothesis postulating the inverse.

The following elementary lemma establishes uniqueness without any
integrality, smoothness, or nonzero-chart assumption. If `I` is an ideal
of a commutative ring `R` and `phi : I -> R` is `R`-linear, then

```
x*phi(y) = phi(x*y) = y*phi(x),    x,y in I.
```

Consequently, if `phi(a) = 1`, every `b in I` satisfies

```
phi(b)*a = b.
```

The map `phi` is injective and its value-one element is unique. In
particular `a_i` is independent of the chosen Bezout coefficients.
All assertions remain valid for a zero chart ring.

This algebra and the finite construction are implemented in
`GeometricSectionInverseIdeal.lean`. `GeometricSeedSectionInverse.lean`
applies them to `chartFactorData` and the actual section `M_i*t`.

## 4. Uniqueness forces the negative-four transition

Restrict the two inverse elements to the common overlap ideal. Since
`phi_j = u^4*phi_i`, both `a_j` and `u^(-4)*a_i` map to one under
`phi_j`. Uniqueness gives the **literal equality of ring elements**

```
a_j = u^(-4)*a_i = (x_j/x_i)^4*a_i.
```

This step is encoded by `sectionInverse_transition`. It is not an
assertion that arbitrary local Bezout choices happen to agree.

Embed `R_i` into its original homogeneous coordinate localization
`A[1/x_i]` and put

```
q_i = a_i/x_i^4.
```

Every `q_i` is a regular homogeneous element of degree `-4` in that
localization. On each overlap,

```
q_j = ((x_j/x_i)^4*a_i)/x_j^4 = a_i/x_i^4 = q_i.
```

Localization of a linear map from an ideal is compatible with its ideal
inclusion. The existing actual overlap comparisons therefore suffice;
no separately postulated global internal-Hom sheaf is needed for this
argument.

## 5. There are no such nonzero compatible negative-degree sections

Here is a direct proof for this actual ring, which does not require
choosing a single cubic symmetry character.

Set `B = C[z1,z2,z3]`. First quotient `B[z0]` by `h`, a monic cubic in
`z0`. Then adjoin `w` and quotient by `G`, a monic cubic in `w`. Thus

```
A is free over B with homogeneous basis
  z0^a*w^b,  0 <= a,b < 3.
```

These basis degrees are `a + 2*b`, all nonnegative. The same basis
remains free after localizing in any of `z1,z2,z3` or their products.
Write the compatible `q_i` in that basis. Their coefficients are
compatible elements of `B[1/z1]`, `B[1/z2]`, `B[1/z3]` and hence lie in

```
B[1/z1] intersection B[1/z2] intersection B[1/z3] = B
```

inside the fraction field of `B`. The equality follows by unique
factorization: a reduced denominator dividing a power of each of three
distinct polynomial variables must be a unit.

The coefficient of `z0^a*w^b` would have degree `-4-a-2*b`, which is
negative. A polynomial in `B` of that degree is zero. Every coefficient
is therefore zero, so all `q_i`, and then all `a_i`, are zero.

The existing `GeometricSeedNegativeSections.lean` implements the
corresponding homogeneous-gluing vanishing in the original localization
rings. Its stated interface also retains a cubic character; the proof
above works degreewise without requiring a character choice. Applying
that interface formally requires the appropriate graded comparison or
finite character decomposition; that step is not silently omitted.

At least one chart is nonzero. For example, on `z3 = 1` choose complex
numbers `a,b` with

```
a^3 = i-1,  b^3 = 2*i.
```

Then `(z0,z1,z2,z3,w) = (0,0,a,1,b)` satisfies `h = G = 0`, since
`a^6 = (i-1)^2 = -2*i`. This is an actual point of the same surface,
independent of `t`. On its chart `phi_i(a_i) = 1` contradicts `a_i = 0`.
This proves the written nonemptiness claim.
