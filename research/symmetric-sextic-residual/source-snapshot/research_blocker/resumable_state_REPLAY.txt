RESUMABLE NATIVE F4: REPLAY NOTES
================================
Frozen implementation, 7 November 2026

Proof scope
-----------
This is a computational repair for an unfinished finite-field Groebner basis
calculation. A checkpoint is not a Groebner basis or a trace certificate.
Neither a full target quotient nor any of the nine requested trace identities
is claimed by the driver or its regression receipts.

Replay
------
From the directory containing these files, build with:

    python build_resumable.py --native-state

Use the binary path printed by that command. For an old packed checkpoint
without native state, or a fresh packed input:

    BINARY --input previous.hcf --output complete.hcf       --checkpoint next.hcf --seconds 600 --pairs 128 --reset 1 --info 2

The safe-boundary timeout writes BOTH next.hcf and next.hcf.state, then exits75.
A full completed native basis exits0. An error exits2. SIGUSR1 only sets a
sig_atomic_t flag in its handler; the next safe boundary performs the writes.
The time budget cannot interrupt an individual in-progress matrix reduction.
Use the separate bounded runner for process and shared-memory guards.

After a native state sidecar has been obtained, resume with:

    BINARY --input next.hcf --resume-state next.hcf.state       --output complete.hcf --checkpoint later.hcf       --seconds 600 --pairs 128 --reset 1 --info 2

Always retain the packed checkpoint and its matching sidecar together. The
original input sidecar preserving variable names/order should also be kept.
Do not pass --resume-state for the historical checkpoint that has no such file.
Without --resume-state the packed file remains a correct generating-set restart,
but upstream initialization regenerates pairs and can repeat old reductions.

An import-only diagnostic is available:

    BINARY --input previous.hcf --output unused.hcf --import-only 1 --info 0

It prints IMPORT_ONLY, complete:false, import time and peak RSS, and exits before
F4. It does not verify or compute a Groebner basis.

Direct input storage
--------------------
The packed dictionary is streamed once into the native monomial hash. The only
large temporary is one uint32 ID per dictionary monomial. Every derived row is
loaded as native monomial IDs plus 8-,16- or32-bit field coefficients. A128KiB
pair buffer is reused. Only the fixed original-generator prefix is expanded to
flat exponents for future ideal-preserving fallback checkpoints. The target's
prefix is38 small original rows. The previous terms*variables int32 expansion
is absent; for132million terms and38variables that old expansion alone would
have exceeded20GB decimal.

Unsorted terms use a heap permutation; already sorted checkpoint rows are
checked and retained in order. Field coefficient normalization, polynomial
sorting and the upstream degree/homogeneity calculation are preserved on fresh
or generating-set imports. Native state restores the saved row ordering and
sugar degrees instead of recomputing its initial pair queue.

Native state contents and checks
--------------------------------
The packed .hcf format is unchanged. It contains the original-generator prefix
and every non-null current basis row, and is explicitly marked incomplete.
The .state sidecar stores the exact pending pair queue, basis redundancy flags,
saved row degrees, leading-monomial index list, numeric F4 metadata and completed
round number. Ordinary safe boundaries require dense live row indices and
bs->lo==bs->ld. Signature and tracer modes are rejected.

The sidecar uses fixed-width little-endian framing and a pointer-cleared md_t
snapshot. It is pinned to this native metadata ABI and source version; it is
not a general interchange format between unrelated msolve versions. A FNV-1a
fingerprint detects an accidentally mismatched packed basis. That fingerprint
is not cryptographic authentication; distribution receipts supply SHA256.

Restoration removes the duplicate original prefix from the active native basis,
keeps it separately for fallback checkpoints, restores native basis indices,
checks every pair LCM against the componentwise maximum of its two leading
monomials, rebuilds the primary hash/divisor masks and leading masks, starts an
empty symbolic matrix and enters the existing F4 loop WITHOUT initial update.
Pair batch size, reset frequency and verbosity may be selected for the new run.
No consumed pair is regenerated by the state path.

Bounded cached I/O
-----------------
The packed writer flushes its stdio buffer and calls fdatasync after each64MiB
of output. It then advises the completed whole-page range DONTNEED. At final
commit it fsyncs and advises the complete output before atomic rename. After
large input import it advises that owned input file DONTNEED before closing.
These operations address shared cgroup page-cache pressure, which is distinct
from process peak RSS. DONTNEED is a kernel advisory, not a guarantee about all
memory in the shared cgroup. The new code does not discard any native basis data.
An unfinished .tmp.PID file is not a valid checkpoint; only a fully committed
file with the declared byte count is usable.

Pair-selection bounds repair
----------------------------
The pinned upstream selector used ps[nps+1] while only checking nps<npd.
That could consult the non-live tail when npd equals the pending queue length.
Its stale value changed batch grouping in a strict restart regression.
msolve_pair_selection_bounds.patch instead starts from the last selected pair,
ps[nps-1], and extends the selection while nps<npd and ps[nps] has that LCM.
The selected prefix is therefore extended only through the same contiguous LCM
group, with every read inside the live queue. This repairs batch boundaries;
it does not delete pending pairs or change their polynomials. Restore also
reserves a spare pair slot. This explicit repair was authorized and tested.

Other native changes and their scope
-----------------------------------
msolve_compact_hash.patch compacts ordinary primary-hash entries in place while
preserving all referenced basis monomials and all pending pair LCMs.
msolve_selective_columns.patch inserts only matrix columns referenced by surviving
rows in the ordinary signature-free finite-field NO_TRACER converter. Its
original blanket converter remains available to tracing, saturation, final
reduction and all other callers. No claim of compatibility with every native
mode is made. The driver itself only accepts the supported finite-field path.

These checks establish the tested implementation behavior, not the target proof.

    python check_native_state.py
    python check_resumable.py --build-receipt resumable_state_build_receipt.json       --output-receipt resumable_state_validation_receipt.json

The latter also needs vendor/libneogb_original.so as an independent native
reference. It can be rebuilt directly from the minimal pinned source subset:

    gcc -O2 -fPIC -shared -D_GNU_SOURCE -Ivendor/gmp-6.3.0       -o vendor/libneogb_original.so vendor/msolve-0.11.0/src/neogb/gb.c       /usr/lib/x86_64-linux-gnu/libgmp.so.10.5.0 -lm

On a different system, use its supported GMP development header/library and
record the changed toolchain. The historical build_neogb.py additionally reads
archive hashes and is not needed for this minimal rebuild.
