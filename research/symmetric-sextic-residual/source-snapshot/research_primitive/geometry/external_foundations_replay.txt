PORTABLE STATIC REPLAY

Keep these beside this note:
  audit_openai_foundations.py
  openai_foundations_static_receipt.json
  openai_OAI_tree_integrity.json
  openai_foundations_sources.tar.gz
  external/openai_foundations_closure_index.json

Run (the script extracts the local archive if the source directory is absent):

  python3 audit_openai_foundations.py --local-only

This rehashes and reparses every extracted source, checks every import in the
closure, and checks the absence of the listed admission/axiom/native-evaluation
tokens outside comments and strings. It writes openai_local_source_replay.json.
It needs only Python's standard library. It does not invoke Lean or validate
the source elaboration or theorem axiom sets.

These are THIRD-PARTY, UNCOMPILED SOURCE SNAPSHOTS, not new kernel-checked
modules and not dependencies of the already compiled sextics proof modules.

The 400 MiB partial download and 62 MiB global source index are intermediate
audit inputs and are NOT needed in the portable package. The global OAI Git
tree reconstruction is a recorded completed audit; reproducing that global
tree check requires the complete upstream OAI source tree, not just this subset.
Every extracted file's SHA256 and Git blob hash is in the static receipt.

Use a fresh directory containing the extracted snapshot. The upstream pins are:

  mathlib d13f23b723b8a846827a245b89c10fc7d3f11612
