## 2. The exact operator being tested

Let `P,U,Z,b` be algebraically independent. Define

```
L=P^6+U^2, M=PU^2 b/2, N=PUZ/2,
K=(U^4+U^2)b^3+U(1+Z^6)+ZU^2 b^2/2,
p=N/L-M^2/(3L^2),
q_c=K/L-MN/(3L^2)+2M^3/(27L^3),
m_p=-2M/(3L^2), m_q=-N/(3L^2)+2M^2/(9L^3),
c=P^2 U^4 Z b^2/(48L^2).
```

`q_c` denotes a moving cubic coefficient, not the original pole parameter.
Set `J_ij=p_i (q_c)_j-p_j (q_c)_i`, `f=J_PZ`, `h=J_UZ`.
The unique degree-at-most-five polynomials `u,v` in `Z` over `Q(P,U,b)` satisfy `u f+v h=1`. They are reconstructed by the 12-by-12 Sylvester coefficient matrix.

In coordinate order `(P,U,Z,b)` put

```
w=m_p (q_c)_Z-m_q p_Z,
zP=m_q p_P-m_p (q_c)_P,
zU=m_q p_U-m_p (q_c)_U,
X=(u w, v w, u zP+v zU, 0),
B=(-u J_bZ, -v J_bZ, u J_bP+v J_bU, 1).
```

The exact generic Nambu identities give

```
X(p)=m_p, X(q_c)=m_q,
B(p)=B(q_c)=0, B(b)=1.
```

Write `d=div B` and `g=div(cX)`. The equation tested is

```
B(psi)+d psi=-g.                                      (S)
```

All four moving derivatives act on the coefficients, including `u,v,c`. In the saved cubic-source binding, the complete current identity is

```
sum_j nabla_j((cX_j+psi B_j) k2)
 = R_cub + (g+B(psi)+d psi) k2.
```

A nonzero scalar residual therefore rejects this particular auxiliary current. It is not an obstruction to other currents.

## 3. The Darboux factors really present in this equation

Define the polynomial numerators

```
H_p=12L^2 p,
H_q=108L^3 q_c,
H_Delta=H_p^3+H_q^2.
```

They are genuine polynomials in the four coordinates and

```
4p^3+27q_c^2 = H_Delta/(432L^6).
```

Since `B(p)=B(q_c)=0`, their exact logarithmic derivatives are

```
B(H_p)=2 B(L) H_p/L,
B(H_q)=3 B(L) H_q/L,
B(H_Delta)=6 B(L) H_Delta/L.
```

After multiplying `B` by a common polynomial denominator, with an extra factor of `L` if needed, these become polynomial Darboux cofactor identities. This does not assert irreducibility of the displayed polynomials or classify all Darboux polynomials.

**Important:** `p,q_c` are first integrals. `L` is NOT a first integral. The field of rational expressions generated by the displayed numerator factors and `L` is

```
K0 = C(L,p,q_c).
```

The first test was whether this entire field, rather than just a bounded list of monomials or constant exponent products, supplies a rational homogeneous multiplier.

## 4. Exact theorem: no homogeneous multiplier in K0

**Theorem A.** No nonzero `m in C(L,p,q_c)` satisfies

```
B(m)+(div B)m=0.
```

Equivalently, no rational integrating factor from this field removes the zeroth-order coefficient of `(S)`. There is no degree or denominator bound in this assertion.

### 4.1 Full moving data at the generic b=0 divisor

The canonical Bezout coefficients are regular at `b=0` over `C(P,U)` and specialize to

```
u0=5L^2/(3U^2),
v0=2L^2(4P^6-U^2)/(PU(P^6-U^2)).
```

Direct substitution into the defining operator, independently checked in `verify_geometry.py`, gives

```
B_P|0=-5P^3 U^2 Z/(72L),
B_U|0=-P^2 U^3 Z(4P^6-U^2)/(12L(P^6-U^2)),
B_Z|0=-P^2 U^2 Z^2/(72L),
B_b=1.
```

Differentiation is performed before specializing the independent variables. In particular the full divergence has

```
d|0=-P^2 U^2 Z(59P^12-46P^6 U^2+23U^4)
      /[72L(P^6-U^2)^2],
B(L)|0=-P^2 U^2 Z(5P^6-2U^2)/(12(P^6-U^2)).
```

Thus, after substituting `P^6=L-U^2`,

```
[-d/B(L)]|0
 = -(59L^2-164LU^2+128U^4)
    /[6L(L-2U^2)(5L-7U^2)] = R(L,U).                (R)
```

### 4.2 Why this is a global field obstruction, not a frozen-slice test

At `b=0`,

```
p=PUZ/(2L),
q_c=U/L+64L^5 p^6/[(L-U^2)U^5] = Q0(U).
```

The map `(P,U,Z)->(L,p,q_c)` is dominant. Its exact Jacobian at `(2,1,1)` is `762/4225`, nonzero. Therefore a nonzero rational function of `L,p,q_c` cannot vanish identically or have a denominator identically zero on the generic `b=0` divisor. This justifies restricting any hypothetical `m` to that divisor; no assumption that it is regular at a chosen numerical point is used.

Over `k=C(L,p)`, the rational map `U -> Q0(U)` has degree 8: its reduced numerator and denominator have degrees 8 and 7 and gcd one. The polynomial relation is

```
U^8-L q_c U^7-L U^6+L^2 q_c U^5-64L^6 p^6=0.
```

For hypothetical `m`, the chain rule yields

```
(m_L/m)(L,p,Q0(U)) = R(L,U).
```

The left side belongs to `k(Q0)`. But the reduced rational map `U -> R(L,U)` has degree 4 and is nonconstant. It cannot belong to `k(Q0)`: degrees of nonconstant rational maps multiply under composition, or equivalently the field tower would force its degree to be a positive multiple of 8. Contradiction.

This proves Theorem A over C, not merely over a finite field.

## 5. Exact theorem for a character-compatible particular-solution class

The source-serving trial family is

```
psi=c b H(L,p,q_c),      H arbitrary in C(L,p,q_c).       (T)
```

This is not a claim that every possible rational solution has this form. Under the order-three symmetry `(P,U,Z,b)->(omega^2 P,U,omega Z,omega b)`, `p,q_c,L` are fixed and `cb` has character `omega^2`, the required scalar character for `(S)`. The full sixth-root covariance further selects odd dependence on `q_c`; the theorem below even allows all H and thus includes the correct subspace.

**Theorem B.** No member of `(T)` solves `(S)`, regardless of the degree or poles of H.

The full source expansion is `g=b^2 g2+O(b^3)`, with

```
g2=P^3 U^4 Z^2(53P^12-34P^6 U^2+17U^4)
   /[1728L^3(P^6-U^2)^2].
```

This formula was independently reconstructed from all three nonzero coefficients of `cX`, retaining the Z product-rule term. Because `B_b=1`, `X_b=0`, and `c=b^2 c2`, the coefficient of `b^2` in the COMPLETE equation forces

```
H|0=-g2/(3c2)
 = -p(53L^2-140LU^2+104U^4)
    /[54U(L-2U^2)^2] = Hforced(L,p,U).                (H)
```

Dominance again makes this a necessary condition on every rational H in K0, not just a preferred zero-initial series. The reduced U-degree of Hforced is 5. Since `Q0` has degree 8, Hforced cannot lie in `k(Q0)`. This proves Theorem B.

Theorems A and B are new tests of natural Darboux-factor classes, NOT proofs that all rational integrating factors, all scalar particular solutions, or the original certificate are impossible.

## 7. What the Doppler-style rationalization does—and does not—do

There is a concrete conic quotient in these variables. After adjoining `ell` with `ell^2=L`, set

```
U=2 ell r/(1+r^2),
P^3=ell(1-r^2)/(1+r^2).
```

Then `U^2+P^6=L` holds exactly. This is the same rational-parametrization mechanism as the square-root-removing substitution discussed in the Doppler example.

But the ORIGINAL P coordinate still satisfies

```
P^3=ell(1-r^2)/(1+r^2).
```

The right side has four simple zeros/poles, at `r=1,-1,i,-i`. The degree-three cover is fully ramified at those four points and unramified at infinity. Riemann-Hurwitz gives

```
2g-2=3(-2)+4(3-1)=2, so g=2.
```

Thus the conic quotient is rational, but this fixed-L character-carrying curve is genus two. Dropping the cube root P would lose the order-three character. This is a limitation of that particular coordinate shortcut; it says nothing by itself about existence or nonexistence of the full four-variable or six-variable primitive.
